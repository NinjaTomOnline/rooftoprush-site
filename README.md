# Rooftop Rush Site

Public GitHub Pages package for `NinjaTom: Rooftop Rush`.

## Publish

1. Export from the private app repo:

   ```bash
   bash /Users/ninjatom/Documents/CODEX_ROOFTOPRUSH/Scripts/export_public_site.sh /tmp/rooftoprush-site
   ```

2. Copy or push `/tmp/rooftoprush-site` into the public `rooftoprush-site` repo.
3. Enable GitHub Pages with GitHub Actions as the source.

## Intended URLs

- Marketing URL: `https://ninjatomonline.github.io/rooftoprush-site/`
- Support URL: `https://ninjatomonline.github.io/rooftoprush-site/support.html`
- Privacy Policy URL: `https://ninjatomonline.github.io/rooftoprush-site/privacy.html`

Replace these URLs if a custom domain is chosen before submission.
