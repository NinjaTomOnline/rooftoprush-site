Playing the browser arcade

Fedora Flick: aim with the slider, then press Flick. Use Pause or Resume to stop and continue a shot. On a keyboard, Tab moves between controls and arrow keys adjust aim. Reduced Motion keeps the target still.

Memphis Sniff Squad: choose tiles to find three bags. An empty tile shows horizontal and vertical steps to the nearest remaining bag. There is no timer. Start a new round for a new search.

Both games keep best scores in this browser only. “Clear best scores” removes both scores. Report a browser-game problem with the game name, browser, and what happened.

Useful Details To Include

  • Device model and iOS version.
  • Whether the issue happened during wardrobe throws, Hook, Jet, stumble, or shopping-bag restore.
  • A screenshot or short screen recording if possible.
